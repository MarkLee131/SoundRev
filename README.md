# SoundRev

Artifact for the paper "Sound Belief Revision for LLM Reasoning about Code Execution" by Kaixuan Li, Yixiang Chen, and Hongwei Tao (under submission). The paper describes the method; this repository holds the scripts and the data needed to rerun the experiments.

## Files

| Path | Purpose |
|---|---|
| `code/program.py` | CFG construction, question atoms, execution tracer, and the theories $T_P$ and $T_P^{u}$ |
| `code/build_dataset.py` | Filters CRUXEval and writes `data/bench.json` |
| `code/query.py` | Queries OpenAI models and caches every response |
| `code/jev.py` | Queries TypeSafe Jev |
| `code/revise.py` | MaxSAT and model-counting revision, MUS enumeration, correction sets |
| `code/evaluate.py` | Main metrics, written to `data/results.json` |
| `code/robustness.py` | Experiments with $T_P^{\forall}$, truncated traces, and the bootstrap |
| `code/completeness.py` | Comparison of $\mathrm{Mod}(T_P)$ with CFG paths |
| `code/selfrefine.py`, `code/baselines.py` | Self-refine baseline |
| `code/llmtheory.py` | Baseline that revises by clauses generated by GPT-4.1 |
| `code/make_tables.py`, `code/make_figures.py` | Tables and figures of the paper |

`data/bench.json` is the benchmark of 408 functions. `data/cache/` stores the raw OpenAI responses, one JSON line per question. The other files in `data/` are the computed results.

The raw Jev responses are not part of this repository. Their summary numbers are in `data/results.json`, and `code/jev.py` can collect them again with a TypeSafe API key.

## Running

Python 3.12 is required.

```bash
cd code
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Every query script reads `data/cache/` first and sends only the questions that have no stored response, so with the provided cache the OpenAI steps make no API calls. To query again, set `OPENAI_API_KEY` and remove the cache file of that model.

```bash
.venv/bin/python build_dataset.py
for m in gpt-4.1-nano gpt-4o-mini gpt-4.1-mini gpt-4.1; do .venv/bin/python query.py $m logprob; done
for m in gpt-4.1-mini gpt-5-mini; do .venv/bin/python query.py $m sample; done
.venv/bin/python query.py gpt-5-mini reason
.venv/bin/python selfrefine.py gpt-4o-mini__logprob gpt-4.1-mini__logprob gpt-4.1__logprob
JEV_API_KEY=... .venv/bin/python jev.py
.venv/bin/python evaluate.py gpt-4o-mini__logprob gpt-4.1-nano__logprob gpt-4.1-mini__logprob gpt-4.1-mini__sample gpt-5-mini__sample gpt-4.1__logprob jev-1.13.0__jev gpt-5-mini__reason
.venv/bin/python robustness.py
.venv/bin/python completeness.py
.venv/bin/python baselines.py
.venv/bin/python llmtheory.py gen
.venv/bin/python make_tables.py
.venv/bin/python make_figures.py
```

All steps after `jev.py` expect the Jev cache file to exist.
